📚 Student CRUD Application
React + Spring Boot + MySQL

A simple Create, Read, Update, Delete (CRUD) project built using:

React + Tailwind CSS (Frontend)

Spring Boot (Backend)

MySQL (Database)

This project demonstrates a minimal full-stack setup where you can manage Students (name + email).

🚀 Features

✔ Add Student
✔ Update Student
✔ Delete Student
✔ View All Students
✔ Fully connected frontend + backend
✔ Uses Axios for API calls
✔ Clean UI using Tailwind CSS

🛠️ Tech Stack
Frontend

React

Axios

Tailwind CSS

Backend

Spring Boot

Spring Data JPA

MySQL Driver

Lombok
